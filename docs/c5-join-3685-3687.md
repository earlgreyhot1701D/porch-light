seven never attempted ES (EN failed first, so ES=0 attempts). Grouping the 6 attempted
ES failures by firing check + reason:

| Count | Class |

**The dominant driver is the descriptive-phrase class, confirmed on a second sample.**
Every failing ES entity is an English descriptive phrase the model translated into
Spanish, which the proper-noun extractor then captured as a raw-compare NAME absent
from the English source:

| `servicios profesionales` | professional services |
| `gas natural` | natural gas |
| `edificio este` | East (building) |
| `desarrollo comunitario` | (Housing and) Community Development |
| `apartamentos loretta court` | Loretta Court Apartments |

This is EXACTLY the class the W6 diagnosis named (role/body descriptive common nouns
that translate freely) — now reproduced on a larger, different sample (Council
consent + Planning). The §45 body-name fix removed the body-name subset; the broader
descriptive-common-noun subset remains and is now the whole story on the entity side.

**Reading level** is the secondary driver: some dense ES rewrites land 56-62 vs the
64.0 floor, and item 4 trips the already-plain-source tolerance (rewrite 69.6 vs
source 78.0, >8.0 harder).

name whose descriptive head noun ("Apartments") translated while the proper part
("Loretta Court") stayed. So the fix cannot be "translate all multi-word phrases" —
it must distinguish a translatable descriptive common noun from a proper name, which
is the same hard line W6 flagged. The shape is: this is a known, characterized class,
not a new failure. **No fix applied — reporting the shape so the fix can be chosen.**
